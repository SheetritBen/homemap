# HomeMap — feature checklist (kill-test prototype)

- [ ] Settings: save + test Anthropic key (stored on-device only)
- [ ] Scan: camera opens, compass permission asked (iOS), auto-capture every 45° (8 shots, 1024px) when held steady
- [ ] Scan: live mini map fills sectors, draws room outline + item dots; "+ item" chips pop in
- [ ] Scan: no compass → shutter captures sectors in order
- [ ] Scan auto-finishes when all 8 sectors are captured and identified; Finish works early (≥4)
- [ ] Upload mode: pick photos → same pipeline
- [ ] Consolidation merges duplicate sightings into one catalog with ₪ estimate + likely Israeli store
- [ ] Item card: free price links (Zap, KSP via Google, Google Shopping IL) + Google Lens via share sheet
- [ ] Cost meter: live $ during scan, "scan cost" saved on each room
- [ ] 3D view: walls from scan, items as sized labelled blocks, orbit/pinch, tap → item card
- [ ] Item card: name/price/store editable, delete
- [ ] Catalog: per-room chips + All, sorted by price, room totals
- [ ] Rescan of a room with the same name replaces it
- [ ] Import scans (Settings) loads an export back; same-name rooms replaced
- [ ] Export scans → one JSON (rooms, items, photos, cost, raw detections/walls) via share sheet
- [ ] `?mock` runs the whole flow with fake detections (no key, no cost)
- [ ] Works at 390px width
- [ ] Capture: uses 0.5x ultra-wide when Safari exposes it ("0.5×" in status); "Hold still…" until compass + gyro are steady
- [ ] 3D layout: sofas/wardrobes/desks flush against walls, desk items on the desk, pillows on sofa, wall art/AC hung on walls (hidden with their wall), chairs face desk, no overlaps
- [ ] 3D models: sofa (arms/cushions/legs), chairs (legs), office chair, desk, monitor (stand + screen), laptop (open lid), wardrobe (doors/handles), AC, printer, bags, pillows…
- [ ] Old scans (no shape data) still render via name-based shape guessing
- [ ] Catalog: small accessories folded into a "Small items" group
- [ ] Room merge sees a labelled photo crop of every sighting (visual dedupe); told distances are unreliable, angles reliable; multi-panel art / sofa bed / one laptop counted once
- [ ] Furniture along the same wall is packed as a row (no piece squeezed inside another)
- [ ] Walking during a scan → "Stay on one spot" warning and auto-capture pauses
- [ ] Heading from gyro (deviceorientation alpha/beta/gamma → camera yaw), compass only as fallback
- [ ] Optional room size (e.g. "3 × 3") before a scan stretches positions to the real size; "Room size" chip in 3D rescales an existing room
- [ ] Windows/doors detected as structure (no price, not in totals, "Room features" group); "+ Window / door" adds one by hand
- [ ] Fix layout: item card → Move → drag on floor (snaps to walls / onto furniture), Rotate 90°, Auto place resets; saved as it.manual and respected by layout
